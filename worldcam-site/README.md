# WorldCam Web Viewer

Web viewer for AI Passport `feature/worldcam`.

- Load public HTTPS camera snapshots directly in the browser, without Passport, NAS, or a local gateway.
- Use the existing WorldCam catalogue.
- Search, filter by country or publisher, browse randomly, and save favourites.
- Previous/next navigation, manual refresh, 60-second automatic refresh, and fullscreen.
- Image copyright and availability are governed by each public source.

Catalogue data is copied from `feature/worldcam/gateway/mobile-test/dist/catalogue.json`.
