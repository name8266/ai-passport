# WorldCam Web Viewer

Web viewer for AI Passport's `feature/worldcam` application.

- The browser loads public HTTPS camera snapshots directly, without a Passport,
  NAS, or local gateway.
- Uses the existing WorldCam catalogue.
- Supports search, country/publisher filters, random browsing, and favorites.
- Includes previous/next navigation, manual refresh, 60-second automatic refresh,
  and fullscreen viewing.
- Image rights and availability belong to the respective public sources.

Catalogue data was copied from `feature/worldcam/gateway/mobile-test/dist/catalogue.json`.
