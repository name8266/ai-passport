# Passport 通知中心 Public 交付验收清单

| 项目 | 软件自动测试 | 客户真机验收 |
| --- | --- | --- |
| 工程构建、分区与镜像尺寸 | 必须成功，镜像不得延伸到 4 MiB 存档分区 | 8 MB 硬件型号确认 |
| 代码与假数据审计 | 禁止模拟通知、演示模型输出、测试 API Key、旧公测标识进入固件 | 全新安装后归档、待办、Wi-Fi 与密钥为空 |
| FreeRTOS 归档命令类型 | CLEAR 使用完整 `archive_control_event_t` 结构体 | 点击清空前确认备份，检查提示及恢复 |
| 主机回归 | 通知解析、持久化、去重、CRC/双槽、旧游标兼容、表单 | 真实 iOS 收发通知和三键操作 |
| ASan / UBSan | 宿主机核心 C 模块无报警 | 运行时堆、栈和 Wi-Fi/BLE/TLS 并发内存 |
| AI | 默认关闭、API Key 不预置、HTTPS CA 校验 | 客户自有 API Key + 通知筛选与摘要正确性 |
| 归档容量 | 满盘、未提交原通知保留、Flash GC 宿主机测试 | 断电/高峰通知/重启恢复 |
| 交付与安装 | 双镜像、中文文件名、SHA-256、全新/升级区分 | 合规授权擦除、安装记录、部署签收 |
| 管理入口 | 已保留开放热点及免登录网页 | 部署客户接受网络访问风险 |

**不得宣称完成的项目：** 72h BLE/Wi-Fi 可靠性、通知捕获率、1,000 次实体通知、反复物理断电测试、真实 RAM 峰值、长期 Flash 耐久、iOS 版本兼容矩阵以及信息隐私安全认证。

**已知限制：** 旧 FATFS 4096→512 字节不自动迁移；低容量 ESP32-C3 的 AI/HTTPS 可能因内存不足延后执行；ANCS 未提供的正文无法恢复；开放热点与后台免登录是本次按要求保留的使用风险。
