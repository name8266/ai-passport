# Passport 通知中心 Public 1.0.0 RC1 — 客户安装说明

适用设备：Passport / ESP32-C3 / 8 MB Flash / 240×320 屏 / 3 键。请先确认设备型号及 Flash 容量，**不要刷到其他 Passport 硬件版本**。

## 固件包包含

- **Passport通知中心-Public1.0.0RC1-全新安装.bin**：bootloader + 分区表 + 工厂应用的合并镜像，仅适合无须保留原数据的全新安装。
- **Passport通知中心-Public1.0.0RC1-应用升级.bin**：仅包含应用，可用于分区表已兼容的现有设备。
- **校验值-SHA256.txt**：两份镜像的校验值，安装前请核对。
- 本安装说明。

需要安装 Python 与 `esptool`（Espressif 工具）。以下命令中的 `<串口>` 替换为实际串口，例如 Windows `COM5` 或 macOS `/dev/cu.usbmodemXXXX`。

## A. 新客户设备：干净安装（会清除所有已有数据）

**确认设备内没有需要保留的通知、Wi-Fi、蓝牙配对或 API Key 之后**，才执行以下操作。该步骤确保旧客户的信息不会残留。

```bash
python -m pip install esptool
python -m esptool --chip esp32c3 --port "<串口>" erase_flash
python -m esptool --chip esp32c3 --port "<串口>" --baud 460800 write_flash 0x0 "Passport通知中心-Public1.0.0RC1-全新安装.bin"
```

注意：全新安装**必须先明确授权**全片擦除。如果刷写失败，不要盲目重复清空仍需保留的设备。

## B. 兼容旧设备：保留配置和存档升级

仅适用于先前已经使用**相同分区表**、相同 512 字节安全磨损均衡归档布局的 Beta 18 / Beta 19（或经核实兼容版本）。升级前先备份重要通知。不要执行 `erase_flash`。

```bash
python -m esptool --chip esp32c3 --port "<串口>" --baud 460800 write_flash 0x10000 "Passport通知中心-Public1.0.0RC1-应用升级.bin"
```

**警告：** Beta 17 及更早版本可能采用 4096 字节 FAT 布局，本版并不提供旧版存档自动迁移。不要假定只刷应用镜像就能读取旧数据。如果存档无法挂载，先停止操作，保留 Flash 原始内容，以免重要数据丢失。

## C. 首次配置

1. 上电检查 Passport 启动，屏幕进入通知中心；新设备应无历史消息和已有待办。
2. iPhone 打开蓝牙设置，配对 **Notify Hub**，同意共享通知；如 iOS 弹出允许访问通知的提示，按使用需求允许。
3. 手机连接设备广播的 `PassportHub-XXXX` Wi-Fi，并打开 `http://192.168.4.1/`。
4. 在设置中填写客户自己的 Wi-Fi 名称和密码；需要 AI 时再填服务商 HTTPS 地址、模型和 API Key，并显式开启 AI。
5. 发送真实系统通知进行冒烟检查：显示应用、标题、预览，累计 3 条时按设定触发 AI；确认已读、隐藏、恢复、单项完成均按预期。
6. 如需离线运行，不开启 AI 即可保存和浏览 iOS 实际提供的通知数据。

**重要：** 当前热点是开放的，无独立网页登录。勿在不可信环境使用；客户应了解此风险后部署。

## D. 验收及故障处理

- 查看编译/回归日志：[GitHub Actions](https://github.com/name8266/ai-passport/actions)。
- 断电后设备应能回到通知中心；出现存档异常应停止反复擦写。只有明确放弃数据时才使用“清空存档”。
- 网站显示“待办已满”时逐项完成待办，不要为了继续摘要就清除仍需处理的事项。
- AI 失败后未处理通知原则上仍保留在设备中；满盘或输入队列溢出则可能无法保存，并会显示警告。
