# 霓虹游乐场 · 经典游戏合集

全中文离线小游戏合集：经典老虎机、多线老虎机、仿真轮盘、俯视骰子与弹珠落盘。

## 游戏模式

| 模式 | 玩法 |
| --- | --- |
| 经典三轮老虎机 | 连续卷带，中间横线两同图 5 分；三同图按樱桃、柠檬、BAR、铃铛、李子、红色 7 分别得 20/25/35/45/60/100 分 |
| 多线五列老虎机 | 五列三行，共 27 条三同图路径：9 条横线、6 条斜线、12 条三角；横线基础分、斜线与三角双倍；无三同图时每行最左两同图 5 分 |
| 仿真轮盘 | 0–36 共 37 格，转动后查看小球最终落入的号码与颜色 |
| 俯视骰子 | 选择 1–6 枚六面骰子，投掷后查看每枚点数与总数 |
| 弹珠落盘 | 选择 1–10 球，同时释放，逐球碰钉后落入九个槽位，全部落盘后结束一局 |

两种老虎机显示本局分和各自累计分。仅娱乐积分，无充值、下注或兑奖。
弹珠使用各球独立轨迹，不模拟球间碰撞。

## 三键操作

- 主页：短按上/下选择游戏，确认进入；长按确认打开设置。
- 游戏：短按确认开始，长按确认返回主页，短按下切换声音，长按上切换自动连玩。
- 空闲时短按上：老虎机/轮盘切换速度；骰子切换枚数；弹珠切换球数。
- 弹珠改变球数后会停止自动连玩，长按上可以重新开启。

## 设置方法

在主页长按确认 → 上/下选择项目 → 确认修改 → 长按确认返回。

| 设置 | 可选值 | 开机默认 |
| --- | --- | --- |
| 帧率显示 | 开启 / 关闭 | 关闭 |
| 骰子枚数 | 1–6 枚 | 2 枚 |
| 霓虹光效 | 彩虹流动 / 彩虹呼吸 / 双向追光 | 彩虹流动 |
| 声音 | 开启 / 关闭 | 开启 |
| 游戏速度 | 慢速 / 标准 / 快速 | 标准 |
| 老虎机模式 | 经典三轮 / 多线五列 | 经典三轮 |
| 弹珠球数 | 1–10 球 | 1 球 |

切换多线老虎机：设置 → 老虎机模式 → 多线五列 → 返回主页 → 进入老虎机。
骰子与弹珠的速度请在设置内修改。设置与积分仅保存在内存，重启恢复默认且清零。
全离线使用，无需配网或账号登录。背光启动指令为 100%。
