# FoloToy AI Passport 星图塔罗

星图塔罗是一款为 FoloToy AI Passport 设计的全离线简体中文塔罗应用。固件内置完整的
78 张 1909 年 Rider–Waite–Smith 公版塔罗牌、本地牌义、四种占卜方式、历史记录、
收藏和设备设置。使用时不需要账号、网络、云端 API，也不会上传用户数据。

## 主要功能

- 今日指引、单牌问答、三牌阵和凯尔特十字。
- 支持正位、逆位以及结合牌阵位置生成的本地解读。
- 内置全部 78 张牌面，可在牌库百科中离线浏览。
- 自动保存完成的占卜，支持历史翻阅、收藏保护和清理非收藏记录。
- 逆位、声音、亮度、历史及收藏状态通过 NVS 持久保存。
- 非阻塞音效、电量周期刷新、自动降低亮度和自动熄屏。
- 熄屏后第一次功能键操作只负责唤醒，并在熄屏期间软件暂停 ES8311 音频。
- 清理非收藏历史需要二次确认；收藏占满时明确提示未保存，不再静默丢失记录。
- 独立设计的深蓝金色 LVGL 中文界面、双列主页及内置简体中文字体。

## 三键操作

| 按键 | 功能 |
| --- | --- |
| 上 / 下 | 切换菜单、牌位、牌库或历史记录 |
| 确定 | 进入菜单、揭牌、查看解读或修改设置 |
| 长按确定 | 返回上一层或主页 |

一次占卜中的牌全部揭开后会自动保存。在“历史记录”中按“确定”可以收藏或取消收藏；
“设置”中的清理功能会先二次确认，只删除未收藏的历史记录。如果 32 条历史全部被收藏，
新的完整占卜仍会保留在当前界面，但会明确显示“无法保存”，直到用户释放历史位置。

自动熄屏后，第一次功能键操作只负责唤醒屏幕，不会同时触发当前选中的界面动作。

## 编译方法

目标硬件为 ESP32-C3、8 MB Flash、无 PSRAM，需要 ESP-IDF 5.5.3。

```bash
source /path/to/esp-idf-v5.5.3/export.sh
idf.py build
```

交付前运行完整验证与合并固件打包：

```bash
./tools/validate.sh
```

验证脚本会生成 `build/FoloToy-AI-Passport-full.bin`，烧录偏移地址为 `0x0`。
历史与设置能否保留取决于烧录方式：

| 操作 | 塔罗历史和设置 |
| --- | --- |
| 正常断电或重启 | 保留在 NVS 中 |
| 使用生成的 `flash_args` 进行同一分区布局的分段烧录 | 保留；其中 bootloader、分区表和 app 的写入均不覆盖位于 `0x9000` 的 NVS 分区 |
| bootloader 与分区表匹配时，仅在 `0x10000` 写入 app | 保留 |
| 从 `0x0` 写入合并的 `FoloToy-AI-Passport-full.bin` | 不保留；合并文件跨越并覆盖 NVS 地址范围 |

当前分区表没有 OTA app 槽位，因此分段或 app-only 烧录属于开发更新路径，并不是 OTA。
完整镜像仅用于首次安装或有意恢复出厂数据。成功编译不等同于真机验收；屏幕显示、中文字体、
按键、音频、电量读数、持久化、唤醒行为和长时间运行仍需在实际设备上验证。
