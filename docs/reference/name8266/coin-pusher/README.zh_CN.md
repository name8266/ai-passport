# 金币推土机（Passport 街机）

独立开发分支：`feature/coin-pusher-arcade`。开机直达原创推币机界面，不沿用原仓库硬件测试菜单。

## 核心玩法

- 最多 192 枚独立硬币，各自拥有位置、速度、半径、厚度、质量和类型；60 Hz 固定步长求解碰撞，并通过空间网格快速筛选碰撞组合，目标约 30 FPS 绘图。
- 推板周期往复，硬币发生水平碰撞、竖直重力、底层平面挤压和简化层叠、边界反弹和台边掉落；中央落袋奖励虚拟积分，两侧沟槽为损失。
- 铜币基础 1 分、金币 3 分、红宝石币 15 分、巨币 9 分。连续 2.4 秒内落袋提升连击倍数（最高 5），投币会累积奖池。
- 随机事件直接作用于物理：金币雨、磁场吸引、地震震动、三倍黄金时刻、月球低重力、虫洞传送、黑洞吸附和奖池大奖。
- **三按键**：上/下移动落币位置；确定单击投币，双击花 6 虚拟币触发事件，长按暂停/继续；上键或下键双击触发液压增压，满载时继续单击确定也会尝试增压，且不会扣币。无币时双击可领取 30 枚免费虚拟币。
- **完全离线**：在余额变化后约 5 秒存档，空闲时约 30 秒刷新一次 NVS 场景快照，保留硬币、余额和奖池；支持迁移旧版 72 枚硬币存档。没有真实货币充值、兑奖、转账或联网博彩功能。

## 技术界限

目标为 ESP32-C3 / 240×320 / 8 MB Flash / 无 PSRAM。使用固定物理对象池和单个 LVGL 绘图回调，不再为每一枚金币分配 UI 控件，也不建立完整画面缓冲。这里实现的是**有体积和厚度的 2.5D 圆柱模拟**，不是完整六自由度刚体：暂时没有金币翻滚、倾斜、转动惯量，也不能宣称与实体推币机相同的摩擦系数。

中文采用 LVGL 内置 Source Han Sans SC 16 子集，缺字则退回英文；中文字形、30 FPS、内存峰值和掉电保持都需要实机验证。

主机物理测试：
```sh
cc -std=c11 -Wall -Wextra -Werror -Imain tests/test_pusher_physics.c main/pusher_physics.c -lm -o /tmp/test_pusher
/tmp/test_pusher
```

防卡机制：当币堆不少于 142 枚且连续 9 秒未有金币掉出时，自动尝试开启 3.2 秒液压强推，7 秒内不会重复触发；硬币不会被凭空删除。

下一步：ESP-IDF 5.5.3 编译、真机测试、多层碰撞调整、音效、粒子动画、大奖演出、实测帧率与堆内存优化。此版未新增或修改编译工作流。
