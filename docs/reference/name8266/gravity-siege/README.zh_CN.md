# Gravity Siege（重力攻城）— Passport 物理街机

这是完全独立的新应用，**不是**推币机、柏青哥，也不继承 BSP 硬件测试菜单。

## 游戏玩法

把橙色重型弹丸发射至由青色易碎球与灰色石球组成的目标阵地。
运动、碰撞、反弹、摩擦与滚动由物理求解器计算。击中底部可以引发倾倒，
击中上层可以打散结构。每关可发射 5–8 次（随着难度增加提供更多弹药）；清除全部青色目标即可过关。
连续击破提高连击得分，通关另加 250 分。

- **上键短按：** 抬高发射角 5°
- **下键短按：** 降低发射角 5°
- **确定短按：** 发射／进入下一关／失败后重试
- **上键长按：** 切换三级发射力度
- **下键长按：** 开始新的一局（总分清零）
- **确定长按：** 暂停／继续

## 物理引擎

`main/kinetic_core.c` 与 UI、ESP-IDF 解耦，基于二维圆形刚体冲量求解。
实现重力、不同材质的恢复系数、碰撞穿透修正、库仑摩擦、
转动惯量、滚动、边界反弹，以及由碰撞速度触发的玻璃破碎。
每个 60 Hz 时间步分为两个 120 Hz 子步，每个子步运行三轮接触求解。
倒塌不使用预先编排的动画，破裂还会产生局部冲量，形成连锁反应。

- 固定 28 个物理对象槽位，运行时物理计算不动态分配内存
- 60 Hz 固定物理时间步，屏幕 **目标** 30 FPS
- 可复现随机种子的主机模拟
- 堆叠行数依关卡变化，完全离线运行

局限：当前使用**圆形刚体**，不是任意多边形求解器；
受游戏平衡性约束，物理尺度并未校准为真实 SI 单位。
设备实测帧率、功耗仍需真机确认。

## 编译和验证

```sh
cc -std=c11 -O2 -Wall -Wextra -Werror -Imain \
    tests/test_kinetic_core.c main/kinetic_core.c -lm \
    -o /tmp/gravity-siege-host
/tmp/gravity-siege-host
./tools/validate.sh --static
./tools/validate.sh --firmware  # 需要 ESP-IDF 5.5.3
```

刷机前需要核对固件镜像与存储数据影响，并经用户授权。
本分支的 GitHub Actions 会执行物理主机测试与固件构建验证。
