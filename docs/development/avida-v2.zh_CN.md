# V2 可执行数字生命实验室：实现与可重复性说明

**定位：** 按 Avida 的核心思想实现的嵌入式人工生命系统，并非 Avida 官方原程序，也不声称能够逐位复现其所有实验结果。

## 学术来源

Charles Ofria、Claus O. Wilke（2004）：**Avida: A Software Platform for Research in Computational Evolutionary Biology**，*Artificial Life* 10(2)，191–229，DOI：[10.1162/106454604773563612](https://doi.org/10.1162/106454604773563612)。

实现参考：[Avida 生命周期开发指南](https://github-wiki-see.page/m/devosoft/avida/wiki/Development---Tutorial---Life-Cycle)和[论文原文记录](https://authors.library.caltech.edu/records/2h3br-gvn73)。

核心原则是：**数字生命必须依靠自身基因指令的执行完成内存分配、程序复制与分裂**，不再由外部 C 函数在能量达标时自动产生子代。

## 指令虚拟机

- 基因组为 **10～64 条可执行指令**，定义 26 种 HEADS 风格指令。
- 每个个体拥有指令指针、读写头和流程头、三个 32 位寄存器、两组小栈、部分复制的子代缓冲区及执行痕迹。
- 初始投入 16 个相同的**论文附录 A.3 中的 15 指令祖先程序**：`h-alloc, h-search, nop-C, nop-A, mov-head, nop-C, h-search, h-copy, if-label, nop-C, nop-A, h-divide, mov-head, nop-A, nop-B`。
- 通过互补模板 `A→B、B→C、C→A` 定位流程头；每执行一次 `h-copy` 复制一条指令；`if-label` 检查是否完成特定序列的复制，`h-divide` 进行长度与执行比例检查后才产生后代。
- 逐条复制时随机替换指令，分裂时也允许插入、删除指令；繁殖由程序行为决定，而不是固定周期触发。
- 生态空间为 16×16 个位置，最多 256 个数字个体，采用确定性轮流调度。新生个体优先进入临近空位，空间满后替换临近个体；更快完成程序自复制的基因型可能占据更多空间。
- 每次指令复制的随机替换概率：0、1/1024、1/256、1/64；每次分裂插入或删除概率：0、1/4096、1/1024、1/256。这些是**本项目的参数选择**，不是论文固定推荐值。
- 随机种子及 Xorshift32 内部状态都可以保存，确保同设置、同操作可重复。

## 设备上直接观察的内容

- **生态页：** 256 格实时显示；不同颜色对应遗传谱系，最近复制/突变事件显示白色标记。可切换“谱系”“复制进度”“基因长度”三种观察方式。
- **基因页：** 当前个体的程序计数位置、接下来的六条指令、父代编号、谱系、程序长度及子代复制进度。
- **统计页：** 已执行指令、复制出生、位置竞争替换、复制突变、插入删除、基因型多样性、优势基因型规模。
- **控制页：** 上下键切页；生态页确认暂停/继续，基因页确认切换个体，控制页确认修改突变率。控制页长按上键按原种子重复实验，长按下键切换观察方式，长按确认键创建新实验；其他页长按确认键手动存档。
- 可以通过 USB 串口收集结构化实验记录；保留固件提交与种子信息才可比较实验数据。

## 掉电保存和分区变化

V2 将 factory app 缩小到 `0x7B0000`，在 Flash 最后 `0x7C0000` 起保留 `0x40000` 的专用 `life_data` 数据分区。两个互相隔离的 `0x20000` 存档槽轮流擦写，依靠版本、序号与 FNV-1a 校验从写入中断恢复到最近有效记录。保存整个生态、全部 CPU 现场、复制中的子程序、随机数状态和事件计数。每 **10 分钟**自动保存；暂停和手动操作时也会保存。突然断电可能丢失最近一次存档后的进度，长期频繁写入会造成 Flash 磨损。**刷完整合并镜像可能清空 NVS 与实验分区，不得假定原有设置自动保留。** V1 的 NVS 档案目前不自动迁移。

## 与正式 Avida 的差异

这不是直接移植完整官方 Avida 源代码，而是**限制规模后的 HEADS 指令解释器**。当前使用 64 指令容量、局部邻接空间竞争、简化调度与部分简化的 IO/指令语义。官方 Avida 还有奖励任务、计算 merit、更加完整的突变策略、精细化的实验与分析流程。**因此本项目可以研究自复制和演化，但未经参考实现交叉验证，不能把结果当作原论文的复现实验。**

## 实验验证

1. 宿主机用例验证：零突变时祖先确实通过执行指令产生子代、同种子重放结果完全一致、突变可改变基因、存档损坏被拒绝。
2. 记录：Git 提交、ESP-IDF/LVGL 版本、指令集版本、祖先程序、突变参数、实验种子与实验更新数。
3. 每组至少做 30 个不同随机种子的独立重复实验，按事先固定的指令执行预算比较，并设置关闭突变的对照组。
4. 统计复制率、存活率、基因长度、基因型数量和空间竞争替换事件，报告不确定性与负结果。
5. 逐项拿虚拟 CPU 模板匹配、读写头、复制循环和分裂行为与官方 Avida 或人工演算结果对照，才能宣称对论文具有数值复现程度。
6. 真机验证中文字符、内存余量、启动恢复、USB 数据、Flash 保存及刷新性能。**编译通过不等于设备实验验收通过。**
