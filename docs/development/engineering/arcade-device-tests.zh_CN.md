# Odds Arcade 远程设备测试

`feature/tiny3d-physics` 开发配置启用了 `CONFIG_ARCADE_USB_TEST`。
如需固件不接受开发指令，在 `sdkconfig.defaults` 中禁用此配置。
接口仅使用本地 USB，不写入持久设置，也不启动网络连接。

LVGL 内存池为 96 KB。骰子和轮盘共享 200×168 的 RGB565 画布
（67,200 字节静态 RAM），不再使用变换后的 ARGB 骰子图层。
改变界面或增加对象时，在设备上检查 LVGL 峰值、最大空闲块及最低系统堆。

USB 指令进入与实体按键事件相同的输入队列：

| 指令 | 操作 |
| --- | --- |
| `u`、`d`、`o` | 上、下、确定短按 |
| `U`、`D`、`O` | 上、下、确定长按 |
| `m` | 在游戏动画期间测量实际刷新 10 秒；采样完成前 USB 指令处理会等待 |
| `v` | 文字框裁切、重叠及立方体网格检查；老虎机画面内有意裁切的卷带文字除外 |
| `?` | FPS 显示开关、骰子枚数、霓虹模式、背光指令值、页面、选项、动画、自动连玩、速度、声音、完成局数、堆内存、LVGL 可用内存及 USB 任务栈水位、音频就绪状态、成功 PCM 写入次数及音频错误数、LVGL 峰值使用量及池内最大空闲块 |

指令区分大小写。游戏及页面操作仍由输入任务持有 LVGL 锁执行，
状态查询也持有此锁。此测试不模拟实体按键上的电压变化。

先执行完整的 `./tools/validate.sh` 门禁，再通过
`tools/archive_firmware.py verify` 校验准确的固件归档。
获得 USB 设备操作授权后，若现有分区表兼容，可按归档 `flash_args`
中的偏移刷入归档内的组件镜像。避开合并镜像填充的数据区即可保留 NVS；
不要根据文件名猜测偏移。

使用已激活的 ESP-IDF Python（包含 pyserial）运行：

```bash
python tools/test_arcade_device.py --port /dev/cu.usbmodem101 \
  --log /tmp/arcade-device-test.log --reset
```

此有界测试默认使用 `--rounds 70`，每个游戏自动完成至少 70 局。
覆盖设置、老虎机/轮盘/弹珠的三档速度、骰子的一至六枚、声音切换、
10 秒 FPS 采样、布局检查、动画途中返回及额外 40 次进入、开始、退出循环。
校验骰子枚数、点数及总数一致，并检查弹珠能落入中间槽。
自动测试独占输入序列时，请不要按实体按键。

主页长按确认进入设置，上/下选行、确认修改、长按确认返回。
设置提供 FPS 显示（默认关闭）、骰子枚数（默认两枚）、霓虹效果、声音及速度。
骰子页空闲时短按上改变枚数，其他游戏短按上切换速度。
长按上切换自动连玩、短按下切换声音、长按确认返回主页。
背光启动设为 100%；设置目前仅保存在内存，重启会恢复默认值。
状态响应缺失、游戏超时、检测到运行异常、队列溢出或过多内存未回收时，测试失败。
日志保留在本地，分享前必须审查并脱敏。测试结束时设备停留在主页。

这些检查确认真实硬件上的 UI、动画和音频代码得到执行，
不能确认屏幕实际观感、听感、实体按键触点或电气测量结果。
这些项目须单独报告为未验证。
