# Odds Arcade 远程设备测试

`feature/slot-machine` 开发配置启用了 `CONFIG_ARCADE_USB_TEST`。
如需固件不接受开发指令，在 `sdkconfig.defaults` 中禁用此配置。
接口仅使用本地 USB，不写入持久设置，也不启动网络连接。

LVGL 内存池为 96 KB。静态界面约占 14 KB，带边缘的 ARGB 骰子旋转图层
达到 74×73 像素（每块 21,608 字节），还需绘图任务、样式及碎片化余量。
原先的 24 KB 池以及 64 KB 池都在设备上出现分配失败，后者发生在自动连玩时。
改变骰子尺寸或增加变换对象时，必须保留图层预算，并在设备上验证
LVGL 峰值使用量、最大空闲块及最低系统堆。

USB 指令进入与实体按键事件相同的输入队列：

| 指令 | 操作 |
| --- | --- |
| `u`、`d`、`o` | 上、下、确定短按 |
| `U`、`D`、`O` | 上、下、确定长按 |
| `?` | 页面、选项、动画、自动连玩、速度、声音、完成局数、堆内存、LVGL 可用内存及 USB 任务栈水位、音频就绪状态、成功 PCM 写入次数及音频错误数、LVGL 峰值使用量及池内最大空闲块 |

指令区分大小写。游戏及页面操作仍由输入任务持有 LVGL 锁执行，
状态查询也持有此锁。此测试不模拟实体按键上的电压变化。

先执行完整的 `./tools/validate.sh` 门禁，再通过
`tools/archive_firmware.py verify` 校验准确的固件归档。
获得 USB 设备操作授权后，若现有分区表兼容，可按归档 `flash_args`
中的偏移刷入归档内的组件镜像。避开合并镜像填充的数据区即可保留 NVS；
不要根据文件名猜测偏移。

使用已激活的 ESP-IDF Python（包含 pyserial）运行：

```bash
python tools/test_arcade_device.py --port /dev/cu.usbmodem101 \
  --log /tmp/arcade-device-test.log --reset
```

此有界测试覆盖每个游戏的三档速度、声音切换、自动连玩、动画途中返回，
并额外执行 40 次进入、开始、退出循环。
状态响应缺失、游戏超时、检测到运行异常、队列溢出或过多内存未回收时，测试失败。
日志保留在本地，分享前必须审查并脱敏。测试结束时设备停留在主页。

这些检查确认真实硬件上的 UI、动画和音频代码得到执行，
不能确认屏幕实际观感、听感、实体按键触点或电气测量结果。
这些项目须单独报告为未验证。

## 已记录的硬件回归

2026-10-06，8 MB Flash、无 PSRAM 的 ESP32-C3 通过完整门禁及带
`--reset --auto-seconds 30` 的 USB 测试：四个游戏共完成 72 局，
覆盖三档速度、声音切换、自动连玩、动画途中退出及额外 40 次切页。
没有重启、看门狗、分配告警或音频错误。
最低系统堆为 140,996 字节，LVGL 峰值使用量为 56,652 字节。
测试前后主页的系统堆均为 145,348 字节；
LVGL 可用内存从 84,224 变为 84,216 字节（保留 8 字节）。
PCM 成功写入 3,171 次，音频错误为零。

已验证的完整镜像 SHA-256：
`614cf5f38ad8aba7ed45b1d0c337491f04c99f55d8f5c158e1caa231d9d70f42`。
匹配 ELF SHA-256：
`7a1a4c3f13dcbd7d8a545967d0859d42e2e36f819572696e2cdfaf99049f55fa`。
设备在 `0x0`、`0x8000`、`0x10000` 收到归档中匹配的 bootloader、
分区表和应用镜像，NVS 位于写入范围之外。
屏幕观感、实际听感和实体按键操作尚未验证；USB 事件覆盖应用输入路径。
