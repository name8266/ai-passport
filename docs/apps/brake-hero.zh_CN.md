# Brake Hero 2.1 工程说明

## 源码与范围

旧 GitHub 产物分支不含游戏源码。本次以 `869d212ac12d6b994604581000bdc3bfdfa39465` 为基线，从原开发聊天保存的完整差异恢复源码，再从已刷完整镜像（SHA256 `6128ab20f18f0db50d13d2aab459975abfb85579771b33bf0c175f5b4f939940`）恢复显示尺寸 PNG、位图字库和 PCM8 音频。本修复的全部编译输入均已保留。本地未取得原始大图集及高精度语音合成输入，详见[素材清单](../../assets/README.zh_CN.md)。

## 第三人称车辆

`brake_vehicle.c` 现在把保留的细节车尾贴图和带纹理的活动顶篷放入与道路一致的居中坐标系。旧版只给车身使用偏航视角，道路仍正对中央，导致车辆像在斜穿车道。新版保持零偏航、零侧倾，并加入轮廓居中回归检查。车身以官方外观为参考，通过内置 image_gen 生成，原始 RGBA 和完整提示词保存在 `assets/images/brake-hero/source/vehicle-rear-v21.png` 及相邻 `vehicle-rear-v21-prompt.txt`。运行时车身为 136×123 索引像素，车漆/玻璃/镀铬与场景共用加权生成的 223 色纹理调色板。不增加逐帧内存分配或整屏解码。这是游戏美术，不是厂商 CAD 或真实碰撞数据。

`bh_vehicle_pose` 将与物理及中文 HUD 相同的连续 0–100% 帐篷值转换成顶壳抬升高度。前铰接硬壳和两侧布面同步升降，松键后也持续收回。有效踏板力点亮左右尾灯及高位刹车灯；游戏中刹车断裂后熄灭。碰撞以游戏撞击速度及经过时间控制前部挤压、玻璃裂纹、碎片和扬尘；坠崖呈现俯仰及下落。损毁画面保留 2.6 秒再进入结算。这些是游戏表现，不是真车损毁验证。

## 显示与音频调度

旧镜像真机日志中，CPU0 IDLE 在 `taskLVGL`、`brake_render` 运行时触发看门狗，记录帧率 8.79 FPS、最大帧间隔 122234 us。这证明存在调度/性能问题，但不足以独立确定全部声音故障根因。

新运行时直接复用 BSP 的 ST7789 面板，不启动 LVGL。唯一渲染任务持有 77824 字节索引帧、一份 19200 字节（240 × 40 × 2）DMA 条带及 512 字节 RGB565 线序调色板。传输完成中断释放信号量，收到完成信号后才复用条带。每次传输超时为 150 ms；失败后停止渲染，不释放可能仍被 DMA 使用的缓冲。输入和声音不再等待整屏 LVGL 锁；索引帧最终仍应用原有圆角屏遮罩。

唯一音频任务优先级为 5，高于渲染任务的 2，低于短时逻辑任务的 6。保留紧急事件抢占、有界队列、重开取消和 20 ms PCM 分块，依靠 I2S 阻塞写入控制流速，不在分块间额外睡眠。日志增加片段播放期间的最大送数间隔，便于真机对照 BSP 最多约 90 ms 的 I2S DMA 容量；播报之间的有意静音不计入欠载。此修改处理已观察到的调度问题，实际听感仍待真机确认。

物理仍按时间戳以 60 Hz 推进，与帧率独立。保留三个控制量独立回落、精确的 1600 N 边界、局内永久刹车断裂、500 米赛道、障碍选择、前十成绩格式及 CRC 存储。仅在合格结果后，由独立低优先级任务提交成绩。

## 字库与回归检查

14 像素 Noto SC 位图字库覆盖源码固定文本及可打印 ASCII。转换器拒绝源字体缺字，并记录 `assets/fonts/brake-hero/inventory.json`；测试保留已知不存在的 U+9F98 负例。油门、帐篷开度、刹车力度等驾驶提示已中文化，通过共用的主机渲染器检查布局。字库编译成功不等于真机显示验证。

`tools/test_brake_hero.sh` 覆盖带时间戳的物理、成绩 CRC/跨进程恢复、导航、音频抢占及重开取消、连续 PCM 分块的完整采样与末尾短块、帐篷升降、刹车灯、碰撞/坠崖状态、DMA 行边界及线序。生成 10000 条确定性轨迹；[统计](brake-hero-simulation.json)描述虚构游戏而非真车。额外以地址/未定义行为检测器检查共用车辆渲染器和物理。

ESP-IDF 5.5.3 下运行 `./tools/validate.sh --firmware` 构建并归档已校验的合并镜像，再用 `python3 tools/archive_firmware.py verify <archive>` 验证对应归档。完整仓库门禁仍遇到基线已有 WorldCam README 双语错误，单独报告且不屏蔽。主机故障注入测试不证明设备时序。
