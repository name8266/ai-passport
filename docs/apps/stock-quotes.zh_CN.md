# A 股股票看板

分支：`feature/stock-quotes`。目标为 FoloToy AI Passport：ESP32-C3、
240 × 320 屏幕、8 MB Flash、无 PSRAM、ESP-IDF 5.5.3。

## 页面与按键

启动进入独立设计的自选行情页面，使用股票专用布局和导航。
支持最多 12 个不重复的沪、深、北交所六位股票代码，首次启动显示示例 `000001`。

| 页面 | UP / DOWN | OK | 长按 UP | 长按 OK |
| --- | --- | --- | --- | --- |
| 自选列表 | 选择股票或添加行 | 查看日 K 线或输入代码 | 刷新行情 | 打开配网 |
| 代码波轮 | 当前位加减，0–9 循环 | 下一位，第六位确认查询 | 返回上一位 | 返回列表 |
| 股票详情 | 移动 K 线游标 | 刷新报价和 K 线 | 添加或删除自选 | 返回列表 |
| 配网 | — | — | — | 返回列表 |

波轮初始代码为 `000001`，根据代码自动识别交易所。
只有返回有效报价才能添加自选。自选存入 NVS 的 `stocks/watch_v1`，重启保留；
重复代码和超过 12 只会被拒绝，删除时移动后续条目并保存。

列表显示名称、代码、最新价和涨跌幅，红涨绿跌。
详情显示最近 60 根前复权日 K 线，游标可查看日期、开盘、收盘、最高和最低价。
详情顶部使用当前不复权报价，与前复权 K 线的价格基准可能不同。

## 网络与数据时间

实现使用无需 API Key、账号、网关或订阅的公开接口：

- 报价：`https://qt.gtimg.cn/q=sh600519,sz000001`，GBK 编码，批量请求。
- 日 K：`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,day,,,60,qfq`，JSON。

这些接口来自腾讯公开网页，未提供本应用的服务保证；格式、可用性或访问政策可能变化。
列表或详情每 30 秒刷新一次，显示行情源时间；休市、节假日显示最近交易时段的数据。
网络失败保留上次成功数据，并明确提示旧数据；失败的代码不会变成有效的零元报价。
支持手动刷新，无效代码或缺失日 K 数据会提示错误。

HTTPS 正常验证证书，使用证书包和 SNTP 校时。网络、解析在独立任务执行，
按键回调只入队；页面切换通过代次编号丢弃过期请求结果。
K 线用 LVGL 绘图原语绘制，不分配整屏图像缓冲。

未配网时连接开放热点 `Stocks-XXXX`，浏览器打开 `http://192.168.4.1`，
填写 2.4 GHz Wi-Fi。沿用 WorldCam 的 Wi-Fi 凭据命名空间，兼容分段烧录可保留配网；
自选使用独立命名空间，不改动 WorldCam 配置。

## 编译与验收

激活 ESP-IDF 5.5.3 后运行完整 `./tools/validate.sh`。
包含市场识别、价格解析、GBK 转换、波轮、自选持久化、报价及 OHLC 校验的纯 C 测试，
以及字体覆盖与位图边界检查。字体来自 Noto，使用 `assets/fonts/` 中已有的 SIL OFL 1.1 许可。
通过 `tools/fetch_worldcam_font_source.py` 获取固定版本源字体后，可运行
`tools/generate_stock_font.py --converter <lv_font_conv-1.5.3>` 重新生成。

本分支 GitHub Actions 编译并提供经过校验的合并固件下载。
从 `0x0` 烧录合并镜像会清除 NVS 设置；保留 Wi-Fi 和自选时，先验证分区兼容，
再按记录的地址分段烧录对应 bootloader、分区表和应用。应用单独镜像不能写到 `0x0`。

真机验收需要覆盖：屏幕和股票名称、波轮数字循环及返回、代码查询、添加删除及重启保存、
列表导航和刷新、K 线游标及刷新、配网、断网旧数据提示和恢复。
主机测试或编译通过不代表真机验收通过。
