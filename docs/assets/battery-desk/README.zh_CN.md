# Battery Desk 电池资产工作台

Battery Desk 将 FoloToy AI Passport 变为小巧的本地电池资产管理终端。
从 `main` 创建 `feature/battery-assets` 开发分支。沿用 `components/bsp` 中的
板级驱动；资产、存储、时钟、网络和界面逻辑均在 `main`。应用不编译、不导航到基线 demo UI。

## 已实现功能

- 全新竖屏设备界面：总览、资产编号卡片、快捷操作选择与确认、手机工作台连接页面。
- 响应式 Web 后台：库存统计、状态分布、最低电量图、搜索筛选数据表、详情与编辑弹窗、
  操作历史、CSV 导出和完整 JSON 导出。
- 最多 16 个资产、最近 48 条操作记录，以带版本和 CRC 校验的 NVS 快照持久保存。
  编号稳定且不复用；删除前必须退役并明确确认，仍在历史缓冲中的记录不会随资产删除。
- `nvs_set_blob` 与 `nvs_commit` 均成功后才发布变更；版本冲突会被拒绝。
  存储初始化或数据校验失败时不自动擦除分区，界面显示存储不可用并拒绝写入。
- 按需启动单手机 WPA2 热点，设备上显示动态生成的 12 字符连接密码，每次启动工作台时更换。
  Web 页面压缩后嵌入固件，无 CDN、互联网或付费服务依赖。
- 手机页面打开、刷新、回到前台及可见时约每分钟自动传输 Unix 时间戳和时区偏移。
  两次同步之间由设备单调时钟推进时间。

## 开始使用

1. 在设备总览长按 `OK` 进入手机工作台，再单击 `OK` 开启 Wi-Fi；也可在总览单击 `DOWN` 进入。
2. 连接 `BatteryDesk-XXXX`，输入设备显示的密码。手机提示此 Wi-Fi 无互联网时，选择保留连接。
3. 在手机浏览器打开 **http://192.168.4.1/**，设备自动校时。
4. 新增名称、化学类型、容量、电量、健康度、循环次数、位置和备注，通过详情页修改状态。
5. 在设备上按 `BAT-001` 编号浏览资产并确认快捷操作。结束后，在手机工作台页面单击 `OK` 关闭 Wi-Fi。

设备右上角百分比来自 Passport 自身的可选 CW2017 电量计。
资产电量、健康度是手工登记的数据，本应用不会测量、切换或给外部电池充电，不增加接线。

## 三键操作

| 页面 | UP / DOWN 单击 | OK 单击 | OK 长按 |
| --- | --- | --- | --- |
| 总览 | 手机工作台 | 浏览资产 | 手机工作台 |
| 资产卡片 | 上一个 / 下一个，循环浏览 | 操作选择；空库存进入手机工作台 | 总览 |
| 操作选择 | 选择操作，取消待确认动作 | 第一次选择，第二次确认并持久保存 | 资产卡片 |
| 手机工作台 | 总览 | 启动 / 停止 Wi-Fi | 总览 |

双击和非 OK 长按没有绑定动作。熄屏后的第一次操作只唤醒，不执行资产变更。
设备无按键操作 45 秒后背光降至 15%，120 秒后熄屏。返回总览不会停止已开启的工作台，
须在工作台页面主动关闭。Web 服务需要 CPU 保持运行，本版本未实现、未声称支持深睡眠。

设备 UI 使用英文与支持的 Montserrat 14/20/28 字体。任意 UTF-8 资产名称在浏览器完整呈现，
设备显示稳定 ASCII `BAT-xxx` 编号，避免中文名称出现缺字方框。中文名称与位置仍完整保存并可导出。

## 数据与状态规则

| 当前状态 | 允许操作 |
| --- | --- |
| 可用 | 领用、开始充电、送检维护、退役 |
| 使用中 | 归还、退役 |
| 充电中 | 完成充电、退役 |
| 维护中 | 完成维护、开始充电、退役 |
| 已退役 | 编辑元数据、删除 |

所有状态都可以编辑档案字段。状态必须通过操作接口修改并记录，编辑不能绕过状态机。
完成充电会把登记电量设为 100%、循环次数加一，请先确认真实充电已完成。退役不可恢复。
循环次数已满时，完成充电被拒绝；先修正元数据再重试。
“需要关注”统计在役资产中电量不高于 20%、健康度低于 80% 或维护中的电池。

名称、位置、备注支持经过校验的 UTF-8，上限分别为 **63、47、95 字节**，不是字符数。
控制字符和非法 UTF-8 被拒绝。容量为 1–60000 mAh，百分比为 0–100，循环次数为 0–65535。
浏览器新建资产初始为可用。保留原有 NVS/PHY/factory 分区布局，使用独立 `battery_v1` 命名空间。
版本 1 为固定布局快照，启动校验大小、版本与 CRC；未知布局拒绝写入。
不迁移其他应用的数据，不擦除其他命名空间。

历史只保留最近 48 条，新操作会淘汰最旧记录；长期保存请定期导出。
CSV 导出所有资产，不受当前筛选影响。JSON 导出全部当前资产与保留记录，但本版本没有恢复/导入接口。
导出文件可能含资产名称、位置和备注，请按其他库存资料妥善保存。

冷启动时故意显示**当前时间未知**：上次保存的时间无法证明断电经过多久。
未校时仍可操作并持久保存，记录 epoch 为 0，明确显示未校时；后续同步不会给旧记录虚构日期。
有效校时时间为 2024-01-01 至 2100-01-01，时区为 -12 至 +14 小时。
准确性取决于手机系统时间，不是独立授时认证。页面请求串行且有大小限制；HTTP 修改要求
匹配本地 Host/Origin、JSON 内容类型及自定义头。热点密码控制本地访问，面向私人单用户使用，
不提供公网托管或多用户账号。

编辑过程中设备或另一客户端更新数据时，保存拒绝旧版本并保留草稿。
关闭并重新打开编辑窗口，核对最新数据后再保存。网络超时可能导致保存结果未知，
请刷新并检查历史后再操作，尤其不要直接重复“完成充电”。修改请求不自动重试。

## 构建与测试

使用已安装的五个 Passport 技能与 ESP-IDF **5.5.3**：

```bash
source <esp-idf-v5.5.3>/export.sh
./tools/validate.sh --static
./tools/validate.sh --firmware
./tools/validate.sh
```

共享静态门禁包含模型/协议测试、存储故障注入和原有基线测试，无需连接设备。
模型测试覆盖状态转换、版本冲突、数值边界、UTF-8、CRC/版本拒绝、历史环形缓冲和时钟行为。
存储测试使用 NVS/互斥锁桩编译实际存储模块，确认写入或提交失败不会发布变更。
最终门禁保留合并固件及匹配 ELF/MAP，位于 `build/firmware/<full-bin-sha256>/`；使用
`python3 tools/archive_firmware.py verify <archive-directory>` 校验归档。

本地浏览器预览使用合成数据和实际 C 状态模型：

```bash
python3 tests/battery_web_preview.py --seed
# Open http://127.0.0.1:8765/
```

去掉 `--seed` 从空库存开始。预览只在内存保存合成数据，不模拟 ESP-IDF HTTP、Wi-Fi、NVS 或实际 LCD。
自动浏览器测试需使 Node 能找到 Playwright，并安装 Chromium，然后运行：

```bash
NODE_PATH=<directory-containing-playwright> node tests/test_battery_web.cjs
```

默认使用 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 替换。
脚本在本地端口 8766 启动独立测试服务，测试校时、档案与状态操作、冲突草稿保留、UTF-8 边界、
转义、筛选、下载、断线恢复，以及 1440/390/320 px 布局。合成截图及导出放在 `build/previews/`。
此项需浏览器安装，作为共享门禁之外的独立测试。

仅在明确授权后，将已校验 `build/FoloToy-AI-Passport-full.bin` 从 **0x0** 烧录。
合并镜像可能重置存储数据，先导出。保留 NVS 需使用兼容的分段烧录，见
[固件布局](../../development/engineering/firmware-layout.zh_CN.md)。应用单独镜像不能烧到 0x0。
云端工作区没有明确 USB 桥接时，无法直接访问你电脑上的设备。

## 真机逐项验收

下列项目在真实 Passport 上观察前均为 NOT RUN。编译、主机测试、浏览器接口或烧录成功都不等于真机验收。

| 项目 | 验收方法 | 预期结果 |
| --- | --- | --- |
| 启动与替换旧 UI | 启动确切已校验固件，遍历页面 | 只有新总览/卡片/操作/工作台，无 demo 菜单 |
| 竖屏显示 | 检查每页、空状态、错误消息与三行操作 | 颜色正常，文字清晰，圆角处不裁切，右上显示自身电量或 `--` |
| 三键操作 | 测试单击/长按/取消，快速切换资产 | 选择及返回正确，不重复执行，按键回调响应正常 |
| 手机流程 | Android/iOS 连接，打开 192.168.4.1，新增/编辑/筛选 | DHCP、压缩页面、表格和图表正常，成功写入在设备刷新后呈现 |
| 手机时间 | 设置已知时间/时区，打开/回前台/刷新，比较设备 | 设备显示与手机一致，仅有传输延迟，记录跟随手机时间，重启后重新校时 |
| 离线持久化 | 关闭 Wi-Fi，执行操作，看到保存成功后断电重启 | 资产状态及历史恢复，校时前记录仍明确无日期 |
| 写入中断电 | 使用可丢弃测试数据，多次保存过程中断电 | 恢复完整旧快照或新快照，不接受损坏记录 |
| 数量与历史边界 | 添加 16 个，尝试第 17 个，执行超过 48 次操作并导出 | 超限拒绝，保留最新 48 条有序记录，导出可读 |
| Web/设备冲突 | Web 保持编辑窗口，设备更改后保存旧草稿 | 版本冲突、草稿保留、最新数据加载，无覆盖 |
| 非法请求 | 超大/畸形/深层 JSON、错误时间、外部 Origin | 400/403/413 或受控超时，无变更、崩溃、自动重试 |
| 重连与生命周期 | 开关工作台 20 次，手机断连/重连，打断请求 | 无残留任务/套接字/网络接口，每次密码变化，断线提示与恢复正常 |
| 内存与栈 | 记录热点启动、满历史读取时堆/最大块及任务栈余量 | 多轮稳定，连续内存与任务栈足够，不复位 |
| 电量计缺省 | 测试不能读取 CW2017 的设备 | 显示 `--`，资产及 Web 服务仍正常 |
| 闲置熄屏 | 等待 45 秒、120 秒，再按键 | 变暗后熄屏，首次按键仅唤醒，开启的 Web 仍可访问 |
| 升级保留数据 | 导出后执行兼容分段升级或明确完整刷新 | 兼容分段更新保留数据，理解合并刷新影响 |
