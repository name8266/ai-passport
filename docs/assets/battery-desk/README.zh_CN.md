# Battery Desk 与 Blue

这是 FoloToy AI Passport 上的本地电池资产与养护应用。源码位于从 `main`
创建的 `feature/battery-assets` 分支。Web 服务、完整资产、操作历史、提醒设置
和英短蓝猫的成长均保存在设备上，无需外部数据库、云账号、CDN 或互联网。
硬件接口仍在 `components/bsp`，应用与两端重新设计的 UI 在 `main`。
当前应用不编译或进入原始 demo 测试菜单与页面。

## 取消人为的资产总数上限

旧版 16 块资产总数限制已经移除。**16 只是分页大小**，用于控制内存占用。
Web 与终端均能跨页浏览；网页的搜索、状态、关注、待提醒筛选覆盖全部资产。
仪表盘统计全部资产，电量图明确显示当前页的最低电量。CSV 导出不受筛选影响，
包含全部资产；JSON 包含全部资产、完整历史、蓝猫成长和提醒偏好，目前没有恢复导入接口。
历史页面显示最近 48 条，更早的记录继续保存在 Flash 中。

物理容量有限：设备有 **8MB Flash**，其中 **0x4f0000 字节（4.94MiB）LittleFS**
专用于资产和历史，固件分区为 3MiB。页面显示实际存储用量。能存多少块取决于
文件系统开销和不断增长的历史，不承诺物理无限，也没有固定的资产行数限制。
保留 32KiB 写入余量；空间不足时拒绝普通写入，不自动淘汰资产，仍可导出和删除。
编号稳定且不复用。大集合的扫描延迟和真正写满 Flash 的行为仍需真机测量；
140 条主机测试证明了跨页逻辑，不代表真机容量测试。

## 开始使用

1. 在 Blue 首页长按 `OK`，进入手机工作台，再短按 `OK` 开启热点。
2. 连接 `BatteryDesk-XXXX`，输入屏幕显示的随机密码。手机提示无互联网时保持连接。
3. 打开 **http://192.168.4.1/**。网页打开、刷新、回到前台以及可见时约每分钟，
   都自动发送手机真实 Unix 时间和时区，设备随后用单调时钟推进时间。
4. 添加电池，登记电量和健康度；可指定下次检查时间，以及充电检查间隔
   （1–1440 分钟，默认 120）。
5. 在详情中进行领用、归还、充电、完成充电、维护、完成维护或退役；退役后才能删除。

终端右上角电量来自 Passport 自身可选的 CW2017 读数。资产电量和健康度由用户登记。
完成充电会记为 100% 并增加循环次数，请先确认实际充电完成。
应用不会电气测量、切换或给被登记的外部电池充电。

| 终端页面 | UP / DOWN 短按 | OK 短按 | OK 长按 |
| --- | --- | --- | --- |
| Blue 首页 | 提醒 / 资产卡片 | 摸摸 Blue | 手机工作台 |
| 资产卡片 | 跨页浏览上一块 / 下一块 | 选择操作 | Blue 首页 |
| 操作选择 | 选择操作，取消待确认状态 | 第一次选择，第二次确认保存 | 资产卡片 |
| 提醒 | 跨页浏览全部待办电池 | 声音稍后 15 分钟提醒 | Blue 首页 |
| 手机工作台 | Blue 首页 | 开启 / 关闭热点 | Blue 首页 |

其他按键长按和双击没有分配动作。45 秒无操作后调暗，120 秒后熄屏，首次按键仅唤醒。
热点需要显式开启，仅允许一个客户端，每次开启生成新的 12 字符 WPA2 密码。
返回首页不会关闭 Web 服务。本版没有深度睡眠。
终端使用已有英文字体和 `BAT-xxx` 编号；完整 UTF-8 名称保留在网页和导出中。

## 温柔提醒与成长

在役电池会在电量 ≤20%、充电检查间隔到期、指定检查时间到期、或 7 天未更新时提醒，
显示最早适用的原因。未校时开始的充电会直接进入待检查，避免编造开始时间。
退役电池不提醒。定时检查并不表示电池实际已经充满。

网页提供提醒中心、待办计数及全部待办分页筛选；终端显示计数并能逐块浏览全部待办。
扬声器工作任务合成短促的上升提示音，同一次持续待办每 30 分钟最多重复一次。
音量（0–60）、静音、免打扰时段（默认 22:00–08:00）、稍后 15 分钟均持久保存。
免打扰开始和结束相同表示关闭时段限制。静音和稍后提醒不会隐藏视觉待办。
未校时时不播放声音。扬声器初始化失败不会阻塞应用，并显示不可用状态。
关闭网页后浏览器不再更新，也没有系统级后台推送；设备保持通电时继续检查提醒。

Blue 是蓝灰色、琥珀眼睛的圆脸英短，有眨眼和开心跳跃。
有效养护获得成长：完成充电 +10，完成维护 +8，有效修改档案 +5，归还 +2。
每块电池每类操作每日奖励一次，每日总计最多 40。未校时操作、重复无变化编辑不奖励。
摸摸触发互动但不加分。0/60/120/180 成长值对应四个等级，网页解锁项圈、皇冠和爱心，
终端解锁项圈和金色装饰。成长与连续照护天数掉电保留。
奖励依据用户登记，无法独立验证真实充电；请按实际需要充电，不要为了分数充电。

## 持久化、迁移与时间

LittleFS 为每个编号保存带 CRC 的独立资产文件，另有元数据和追加式 CRC 历史文件。
事务意图包含新资产、历史记录、元数据：先同步意图，再更新资产、恰好一次地追加历史、
原子替换元数据，最后移除意图。重启先幂等恢复已持久保存的未完成事务，再开放存储。
请求失败时保存结果可能未知，恢复后先检查状态和历史再重试。
版本冲突拒绝过期编辑，保留网页草稿。

仅完全擦除的新资产分区允许自动格式化。非空分区挂载失败、旧 NVS 损坏、未知元数据
或损坏的待恢复事务都停止使用存储，不自动擦除。终端仍显示错误并可进入工作台。
初始化不擦除其他 NVS。旧 `battery_v1` 的资产和历史会迁移并保留编号，源 NVS 不修改。
进度标记支持迁移恢复，防止迁移后删除的旧资产在重启时复活。

每次冷启动真实时间未知，因为 Flash 时间戳不能推算断电时长。离线操作保存 epoch 0，
后续校时不会编造历史时间。断电重启后，绝对时间安排、成长奖励、免打扰和定时声音
需要手机重新校时。有效时间为 2024–2100，时区 −12 至 +14 小时；精度取决于手机时钟。

名称、位置、备注允许有效 UTF-8，分别最多 63/47/95 **字节**。容量为 1–60000mAh，
百分比 0–100，循环次数 0–65535。编辑不能绕过有历史记录的状态操作。
JSON 请求最多 1536 字节，拒绝不安全内容、重复字段和外部请求来源。
热点密码控制本地访问；这是没有账号或互联网托管的私人工作台。

## 构建、浏览器验证与烧录

使用 ESP-IDF **5.5.3** 和五个必需的 Passport 技能：

```bash
source <esp-idf-v5.5.3>/export.sh
./tools/validate.sh
python3 tests/battery_web_preview.py --seed
# 合成数据预览：http://127.0.0.1:8765/
NODE_PATH=<包含-playwright-的目录> node tests/test_battery_web.cjs
```

完整检查包含仓库检查、模型/协议、真实文件引擎的 140 条分页、四个事务中断阶段、
CRC 拒绝、迁移、奖励封顶、免打扰、ESP 包装层挂载/空间/锁故障，以及已有 BSP
按键和音频恢复测试。网页预览通过生产 C 存储引擎运行在主机临时文件系统上，不是真机模拟器。
浏览器测试覆盖 33 块资产、全部待办、全局搜索、超过 48 条历史的导出、奖励与摸摸、
设置/稍后提醒、CRUD、冲突、转义、断线恢复以及 1440/390/320 像素布局。
合成截图保存在 `build/previews/`。

验证后的 `build/FoloToy-AI-Passport-full.bin` 从 **0x0** 烧录，匹配的 ELF/MAP 和分段镜像
在 `build/firmware/<完整镜像-sha256>/`。使用
`python3 tools/archive_firmware.py verify <归档目录>` 验证。

**从旧 Battery Desk 升级且需要保留 NVS 以迁移时**，先导出，再使用对应归档的分段
`flash_args`（bootloader 0x0、分区表 0x8000、应用 0x10000）。不要直接用完整合并镜像
覆盖旧 NVS，其填充区域可能清掉旧数据。新布局：NVS 0x9000/0x6000，PHY 0xf000/0x1000，
factory 0x10000/0x300000，assets 0x310000/0x4f0000。此布局下的兼容分段升级不写两个数据分区，
不烧录文件系统镜像。不要将仅应用镜像写到 0x0，也不要把整片擦除当成升级步骤。
资产区域存在不兼容非空内容时，需要明确选择恢复方式，应用不会静默擦除。
详见[固件布局](../../development/engineering/firmware-layout.md)。
可选的实际终端组件渲染检查（先由 IDF 解析安装 LVGL）：

```bash
cmake -S tests/lvgl_preview -B build/screen-preview
cmake --build build/screen-preview
mkdir -p build/previews
build/screen-preview/battery_screen_preview build/previews
```

使用 240×320 RGB565 和配置一致的 32KiB LVGL 池，检查分配器余量，并生成首页、
开心动作、资产、操作、提醒、Wi-Fi 的 PPM 帧。这不验证物理 LCD 或 SPI。
单行文字设置明确高度，多行说明和按键提示限定高度。

USB 烧录需要明确授权，并能够访问用户电脑或 USB 桥接设备。
