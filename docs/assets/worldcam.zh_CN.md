# Passport 全球摄像机应用：世界之窗

世界之窗为 ESP32-C3 FoloToy AI Passport 提供独立的中文地图、快照、全屏和联网配置界面，替换原硬件测试启动菜单。配套 Python 网关获取发布方公开图片，中文网页支持地图、搜索和随机游览。

## 摄像机目录与首都覆盖

本版收录 **825 个公开摄像机信息，覆盖 72 个国家和地区**。检查时 **824 个图片源成功获取并解码**；这只证明当时可访问、图片格式有效，不等于原始拍摄时间新鲜或长期在线。

另有 **195 个国家的主要首都登记点**（193 个联合国会员国加梵蒂冈和巴勒斯坦）。其中 **50 个首都找到公开目录来源，49 个成功取得图片**。**145 个首都在所查目录中尚未找到经验证来源**，另有一个已收录首都来源暂不可用。因此，**“每个国家首都都有可用摄像机”的要求尚未达到**。没有来源的首都仍保留位置，但不会伪造摄像机、用其他城市代替、放入旅游照片或私人暴露摄像机。

`gateway/capital-coverage.json` 记录国家与首都、实际查询链接、查询时间、匹配摄像机、失败查询和取得图片的来源；`gateway/source-audit.json` 记录每个图片源的检查及失败原因。查询来源包括 Foto-Webcam.eu、SkylineWebcams、Webcam Galore，以及首版的 NPS、香港天文台、GeoNet 和美国南极科考计划。不匹配这些目录，不代表整个互联网一定不存在公开来源。

画面为定时快照或发布方的公开预览图，并非连续视频。刷新获取源站最新可提供图片；界面的时间是网关获取时间，不是原始拍摄时间，源站可能保留旧图。配套网页保留原始来源署名和观看链接。设备版目前显示地点、国家和获取时间，尚未显示发布方名称；全屏隐藏文字信息。

## 设备按键

| 页面 | 前后键短按 | OK短按 | OK长按 | 上键长按 | 下键长按 |
| --- | --- | --- | --- | --- | --- |
| 地图 | 前后选择地点 | 查看；目录为空时重试 | 联网设置 | 随机游览 | 全部地点 / 首都筛选 |
| 观看 | 前后切换地点 | 刷新 | 返回地图 | 随机游览 | 切换全屏 |
| 联网配置 | 无操作 | 无操作 | 返回地图 | 无操作 | 无操作 |

随机游览只选择有公开画面的地点，排除无来源和检查失败项；有其他地点时避免重复当前位置。如果之后获取失败，最多另试三个随机地点。观看页面每 60 秒尝试刷新，失败明确显示错误。

全屏隐藏标题、地图、电量和操作说明，画面使用整个屏幕宽度。为保留比例，竖屏上下或图片内部可能留黑边。设备界面为中文，已有中文名称的地点显示中文，部分发布方专有名称保留拉丁文字。全部固定文字和动态地点共使用经检查的 16px 字体子集，覆盖 771 个实际字符（含中文和扩展拉丁文字）；实际屏幕效果仍需真机检查。

## 启动网关

在与 Passport 同一可信局域网的电脑上使用 Python 3.12 或以上版本：

```bash
python3 -m venv .worldcam-venv
.worldcam-venv/bin/pip install -r gateway/requirements.txt
.worldcam-venv/bin/python gateway/server.py --host 0.0.0.0 --port 8787
```

Windows 使用 `.worldcam-venv\Scripts\python.exe` 和 `.worldcam-venv\Scripts\pip.exe`。浏览器打开 `http://<电脑局域网IP>:8787`。默认仅监听本机，`--host 0.0.0.0` 允许设备访问。使用时必须保持网关运行；如有需要，只在可信局域网放行电脑防火墙的 8787 端口。不要将这个无身份验证的本地 HTTP 服务直接暴露到公网。

配套网页支持地图点选、前后按钮、中英文搜索、地区筛选、只看首都、随机游览、刷新、全屏、来源署名与链接。地图聚焦时也可按方向键切换、Enter查看、R随机游览。搜索针对维护目录。

```bash
.worldcam-venv/bin/python gateway/server.py --check-sources --limit 20
```

不加 `--limit` 检查所有来源。`tools/audit_worldcam_sources.py` 可以重新检查并更新维护记录；执行前应审查来源变化与使用条款。网关只获取维护目录里的 URL，验证源站 HTTPS，限制图片大小、像素与并发，每 60 秒缓存一次，最多保留 64 组缓存。失败返回错误，不把旧图重新标成当前画面。

## 构建与连接设备

激活 **ESP-IDF 5.5.3** 后：

```bash
python -m pip install -r gateway/requirements.txt
./tools/validate.sh
```

统一检查包含仓库、主机逻辑、字体和网关测试，并构建验证 `build/FoloToy-AI-Passport-full.bin` 及 `build/firmware/` 下对应调试归档。固件没有编译进去的 Wi-Fi 密码；构建成功不等于真机验收。

1. 确认目标设备、确切固件并授权后才烧录。从 `0x0` 写入完整镜像会替换固件，可能重置 NVS 设置；无需全片擦除。参见[固件数据规则](../development/engineering/firmware-layout.zh_CN.md#flashing-and-stored-data)。
2. 首次启动，按屏幕显示的随机八位密码连接 `WorldCam-XXXX` 热点，打开 `http://192.168.4.1`。
3. 输入 2.4 GHz Wi-Fi 名称、密码和网关地址，例如 `http://192.168.1.10:8787`，末尾不要加 `/`。必须用电脑的局域网地址，`localhost` 指 Passport 自身。
4. 连接成功后关闭配置热点、加载地图目录；失败时保留配置页面供更正。在地图页长按OK可重新配置。配置保存在应用自己的 NVS 命名空间中，重启后保留；换网时在配置页覆盖。本版 NVS 未加密。

BLE已关闭以节省内部 RAM；断网每 10 秒重连。配置热点每次启动使用新的随机密码。NVS初始化错误时不会自动擦除已有数据。

## 测量中国大陆直连可用性

云端图片审计不能作为中国大陆直连结果。当前云端出口 IP 定位服务返回美国，且没有连接大陆测试主机。实际可用数量需从将要运行网关的网络测量。

在大陆电脑上运行这个独立只读检测工具，需要 Python 3.10+ 和 Pillow，无需 ESP-IDF、已启动的网关或 Passport。测试直连时先关闭本地 VPN 和浏览器/系统代理。检测工具默认不使用应用层代理设置，但路由器代理或透明 VPN 仍可能改变实际出口。

```bash
python -m pip install -r gateway/requirements.txt
python tools/probe_worldcam_network.py --vantage-label mainland-local --output WorldCam-mainland-report.json
```

JSON 报告记录每个图片源的成功、失败、发布方汇总和首都覆盖，不修改维护目录。成功只证明测试时图片能获取并解码，不证明拍摄时间实时。报告中的物理网络来源仍为未验证，地点标签仅描述操作者的测试条件。需要与已配置的应用层代理比较时，可加 `--use-env-proxy`，并换一个输出文件名。直连失败不一定代表被阻断，也可能是超时、源站停机、区域限制或访问频率限制。

## 地点与画面协议

设备读取 `/api/index`，避免一次解析全部地点资料。最多支持 2048 个地点，坐标索引最多占 16KiB。

| 偏移 | 长度 | 索引含义 |
| --- | --- | --- |
| 0 | 4 | ASCII `WCIX` |
| 4 | 2 | 地点数，小端 |
| 6 | 2 | 每条记录8字节，小端 |
| 8起 | 每条8 | uint16编号、int16纬度、int16经度、uint8标记、uint8保留零 |

坐标为百分之一度；标记1表示检查时有可获取画面，标记2表示首都，标记4表示已找到公开来源（检查失败时仍可手动重试）。`/api/location/<index>` 返回有长度限制的 UTF-8 地点资料；`/api/frame-location/<index>` 获取此地点对应的维护来源，无摄像机则返回错误。编号顺序来自 `gateway/locations.json`，更新目录时需同步地点、地图和字体。

| 偏移 | 长度 | 画面含义 |
| --- | --- | --- |
| 0 | 4 | ASCII `WCAM` |
| 4 | 2 | 宽，小端 |
| 6 | 2 | 高，小端 |
| 8 | 4 | 网关获取 Unix 时间，小端 |
| 12起 | 宽×高×2 | 逐行小端 RGB565 |

普通画面192×128，总计49164字节；`?full=1` 返回240×160，总计76812字节。设备只接受这些精确尺寸，拒绝错误头部、坐标、UTF-8和截断下载。请求下一帧前释放旧图；LVGL更新与缓存失效处理在BSP锁内进行。按键回调只入队，代次编号丢弃已经离开地点的旧返回结果。

简略世界地图保存在Flash。Foto-Webcam使用发布方坐标；Skyline使用匹配到的GeoNames城市中心。其他条目标明位置精度。地图点是简略位置，不是用于导航的摄像机安装坐标。

## 素材与复现

字体和地图数据来源、许可证见[素材索引](../../assets/README.zh_CN.md)。更改地名或坐标后重新生成：

```bash
python -m pip install fonttools
npm install --prefix .toolchain/fonts lv_font_conv@1.5.3
python tools/generate_worldcam_font.py --converter .toolchain/fonts/node_modules/.bin/lv_font_conv
python tools/generate_worldcam_map.py
```

测试会检查实际生成字体的字符映射、位图边界、每个维护地名及界面文字，并包含已知缺字的反向检查。新增来源应记录公开发布与署名信息，不加入私人或绕过登录的 URL。

## 尚待实机验收

主机测试覆盖投影、索引解析、目录规模与筛选、首都登记完整性、随机选择排除项、UTF-8、两种画面尺寸和颜色、无来源/源站失败响应、字体字符覆盖与位图边界。浏览器检查覆盖地图选择、搜索筛选、随机游览、全屏与图片获取。固件检查针对固定版本ESP-IDF和LVGL，并验证完整镜像布局。

真机仍需检查：全部状态的中文显示、屏幕圆角裁切、地图标记、所有按键手势、全屏色彩与比例、随机失败重试、热点配置及错密码更正、断网重连、堆内存峰值、长时间刷新、重启保留设置、下载中切换地点。尚未执行USB烧录或真机验收。
